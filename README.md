A web based monopoly to play online with friends.

<h2> Instructions</h2>
One player has to host the game server on their machine.<br><br>

1. 𝗚𝗼 𝘁𝗼 𝘁𝗵𝗲 '𝘀𝗲𝗿𝘃𝗲𝗿/' 𝗿𝗲𝗽𝗼𝘀𝗶𝘁𝗼𝗿𝘆 𝗮𝗻𝗱 𝘁𝘆𝗽𝗲 :

  ```bash
  npm install
  ```

  This will install all dependencies.

2. 𝗜𝗻 𝘁𝗵𝗲 '𝘀𝗲𝗿𝘃𝗲𝗿/' 𝗿𝗲𝗽𝗼𝘀𝗶𝘁𝗼𝗿𝘆, 𝘁𝘆𝗽𝗲 :

```
node server.js
```
This will launch the game server.

3. 𝗚𝗲𝘁 𝘁𝗵𝗲 𝗨𝗥𝗟 𝗼𝗻 𝘄𝗶𝗰𝗵 𝘆𝗼𝘂𝗿 𝘀𝗲𝗿𝘃𝗲𝗿 𝗶𝘀 𝗿𝘂𝗻𝗻𝗶𝗻𝗴 𝗮𝗻𝗱 𝘀𝗲𝗻𝗱 𝘁𝗼 𝘆𝗼𝘂𝗿 𝗳𝗿𝗶𝗲𝗻𝗱𝘀.

  To get an URL, I recommend generating one using <a href=https://ngrok.com/>Ngrok</a>. <br>
  When you successfully installed Ngrok, go to the project folder and type :
   
   ```
   ngrok http 3000
   ```
   This will automatically generate an URL and host the website.

4.  𝗘𝗻𝗷𝗼𝘆.
